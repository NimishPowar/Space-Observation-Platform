[] 1. Introduction
[] In today’s fast-paced digital world, managing personal finances effectively has become increasingly important. Many individuals struggle to track expenses, manage recurring payments, and analyze their financial habits.
[] Trackify is a modern full-stack personal finance management system that enables users to track income and expenses, analyze spending patterns, automate recurring payments, and receive AI-powered financial advice.
[] The system integrates advanced features such as:
[] Bank statement PDF import 
[] AI-based financial advisory 
[] Risk score analysis 
[] Data visualization dashboards 
[] Automated recurring expense tracking 
[] Unlike traditional finance apps, Trackify provides intelligent insights and predictive analysis, helping users make better financial decisions.
[] 1.1. Project Scope
[] TrackifyV2 is a modern, full-stack personal finance management application designed to help users track their income and expenses, analyze their spending habits, and receive AI-driven financial advice. It emphasizes a premium user experience with dynamic data visualization, automated statement parsing, and local AI integration.
[] 1.1. Core Features (Financial Tracking)
[] Authentication & Security: Secure user registration, login, and password recovery using JWTs, alongside Google OAuth integration for quick sign-ins.
[] Transaction Management: Manual entry of daily income and expenses categorized for granular tracking.
[] Bank Statement Automation: Ability to upload PDF bank statements which the system automatically parses using regex to extract and log transactions.
[] Recurring Expenses: Setup and tracking of subscription or EMI payments (e.g., setting a start date, monthly frequency, and auto-deducting them).
[] Budgeting: Setting global monthly expense limits with visual warnings when nearing or exceeding the budget.
[] 1.2. Advanced Analytics & AI
[] AI Financial Advisor: An integrated chat-like interface that streams personalized financial insights, savings tips, and risk alerts generated by a local Ollama LLM based on the user's actual transaction history.
[] Risk Score Analyzer: A deterministic, math-based algorithm that calculates a 0-100 financial health score by evaluating the user's savings rate and emergency fund coverage.
[] Debt Payoff Calculator: A tool that uses standard amortization formulas to estimate how many months it will take to pay off a specific debt based on the principal, interest rate, and monthly payment.
[] Dashboard Visualizations: Interactive charts (Bar charts for Income vs. Expense, Pie charts for Category breakdowns) built with Recharts to provide an at-a-glance view of financial health.
[] 1.3. Reporting & Data Portability
[] PDF Generation: A one-click, highly-styled, client-side PDF reporting engine that generates audit-ready financial snapshots including charts, AI insights, and transaction history.
[] Data Export: Raw data exportation capabilities allowing users to download their transactions in standard CSV or formatted Excel (.xlsx) files.
[] 1.4. UI / UX Scope
[] Premium Design Aesthetics: Implementation of a glass morphism design system, smooth page transitions (via Framer Motion), dynamic gradient backgrounds, and an automated Light/Dark mode toggle.
[] Responsive Layout: A fully responsive dashboard grid system designed to work seamlessly across mobile, tablet, and desktop devices.

[] 3.6 Risk & Debt Analyzer
[] The Local Risk Score Logic
[] The new logic calculates a 100-point score composed of two 50-point metrics:
[] 1. Savings Rate Score (Max 50 points)
[] Calculates what percentage of your total income is saved. Target: 20% (0.20) savings rate yields a full 50 points.
[] If >= 20%: "Healthy"
[] If >= 10%: "Moderate"
[] If > 0%: "High Risk"
[] If <= 0%: "Critical"
[] 2. Emergency Fund Score (Max 50 points)
[] Calculates how many months of expenses your liquid savings cover. Target: 6 months of coverage yields a full 50 points.
[] If >= 6 months: "Healthy"
[] If >= 3 months: "Moderate"
[] If >= 1 month: "High Risk"
[] If < 1 month: "Critical"
[] 3. Formula
[] Total Score = Savings Rate Score + Emergency Fund Score
[] Final Output
[] The two scores are added together (up to 100) and returned with contextual text explanations matching exactly the JSON format the frontend expects.
[] Shows: 
[] Savings ratio 
[] Expense patterns 
[] Risk alerts

[] 4. Technology Stack
[] Frontend (User Interface)
[] Core Framework: React 19
[] Build Tool: Vite
[] Routing: React Router DOM
[] Styling: Tailwind CSS (with PostCSS and Autoprefixer)
[] Icons: Lucide React & Heroicons
[] Data Visualization: Recharts
[] Animations & Graphics: Framer Motion, Three.js, and CountUp
[] Authentication: Google OAuth (@react-oauth/google) & JWT Decode
[] Export & Reporting: jsPDF, jsPDF-AutoTable, and html2canvas (for PDF generation)
[] Backend (Server & API)
[] Core Framework: FastAPI (Python)
[] Server: Uvicorn
[] Data Validation: Pydantic & Pydantic-Settings
[] Authentication & Security: Passlib (bcrypt), python-jose (cryptography), and Google Auth
[] Database Integration: Firebase Admin (Firestore) and SQLite (configured via Docker volumes)
[] File Processing (Uploads & Exports): PyPDF2 (for parsing statements), Pandas, Openpyxl (for Excel exports), and python-multipart
[] External Requests: HTTPX (used for asynchronous AI/Ollama API calls)
[] Infrastructure & Deployment
[] Containerization: Docker & Docker Compose (orchestrating separate frontend and backend services)
[] Environment Management: python-dotenv for backend secrets and Vite's native env handling for the frontend.
