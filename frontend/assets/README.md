# Assets Directory

This directory stores public visual assets for the Space Observation Intelligence Platform.

## Landing Page Background (`landing_bg.jpg`)
* **Usage**: Used as the dimmed hero background image on the landing page (`frontend/pages/landing.py`).
* **Requirements**: Should be a high-resolution NASA / ESA / ESO public domain space photograph (deep-field galaxy shot, cosmic nebula, or astrophotography).
* **Overlay**: The landing page CSS applies a dynamic dual-gradient overlay (`linear-gradient(rgba(5,6,9,0.75), rgba(5,6,9,0.9))`) on top of this image, so the image does NOT need to be pre-dimmed.
