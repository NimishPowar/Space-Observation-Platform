## Overview

The Space Observation Intelligence Platform is a data-driven web application that helps users discover celestial objects visible in the night sky, plan the best observation time, and understand the science behind astronomical phenomena.

The project combines Data Engineering, Data Analysis, Astronomy, and Software Development into a single platform.
